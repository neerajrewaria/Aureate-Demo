# AUREATE Demo

AUREATE is a demo botanical wellness e-commerce website built with React, TypeScript, and Vite. It showcases product browsing, product details, a cart and checkout experience, brand information, and an admin dashboard demo. It is a frontend demonstration, not a production e-commerce service.

## Getting started

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — type-check and create a production build in `dist/`
- `npm run preview` — preview the production build locally
- `npm run lint` — run Oxlint
